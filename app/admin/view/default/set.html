腾讯云：开通「慧眼-人脸核身」，在控制台「业务流程管理」创建流程得到 RuleId；SecretId/SecretKey 在访问管理(CAM)获取。回调域名需在控制台配置为本站域名。
阿里云：开通「实人认证」，在控制台创建认证场景得到 SceneId；AccessKeyId/Secret 在 RAM 访问控制获取。
支付宝/芝麻信用：在支付宝开放平台(open.alipay.com)创建应用并签约「芝麻信用-实人认证」产品，拿到 APPID 填入ID项；生成 应用私钥 填入密钥项；商户PID(2088开头) 在「账户中心」获取填入场景项。应用需配置 RSA2 签名、应用公钥与支付宝公钥，并设置回调域名。需开通「芝麻信用-实人认证」产品。
用户填写姓名+身份证后将跳转到人脸识别页面完成活体检测，核身通过后自动写入实名信息。调用按实际服务商计费，请确保账户余额充足。

自动：先判断短信是否开启，开启就发短信；短信未开启则判断邮箱是否开启，开启就发邮箱，都不开启则不发。
仅短信：只在短信开启时发送，不降级到邮箱。
仅邮箱：只在邮箱开启时发送。
通知场景：登录成功、注册成功、密码重置成功、产品购买/到期暂停/到期终止、工单提交/回复/关闭、提现申请/处理、产品过户、修改密码等
注意：验证码类短信（注册/登录/找回密码验证码）不受此设置影响，仍按原有逻辑发送。如选择短信或自动渠道，请先在「短信设置」中配置好短信接口，并在此填写通知专用模板。
