# cxym 网盘插件

## 功能特性

- ✅ 支持文件上传下载
- ✅ 支持外链分享
- ✅ 支持密码保护
- ✅ 支持云存储(阿里云OSS/腾讯云COS)
- ✅ 支持本地存储
- ✅ 用户管理
- ✅ 容量限制

## 配置说明

### 基础配置
- **网盘标题**: 显示在首页的标题
- **网盘描述**: 显示在首页的描述
- **最大上传大小**: 单个文件最大上传大小(MB)
- **存储类型**: 本地存储/阿里云OSS/腾讯云COS
- **允许游客上传**: 是否允许未登录用户上传
- **上传后设置密码**: 是否要求上传后设置密码

### 云存储配置

#### 阿里云OSS
- OSS存储桶名称
- OSS Endpoint
- OSS AccessKey
- OSS SecretKey

#### 腾讯云COS
- COS存储桶名称
- COS Region
- SecretId
- SecretKey

### 数据库配置
- 数据库主机
- 数据库名称
- 数据库用户
- 数据库密码

## 安装步骤

1. 上传cxym网盘源码到服务器
2. 配置数据库连接
3. 运行安装脚本
4. 在主机系统中添加插件
5. 创建产品并关联插件

## 注意事项

- 确保服务器支持文件上传
- 确保有足够的存储空间
- 定期备份数据库和文件
